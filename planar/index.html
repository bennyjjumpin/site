Planar

Listen to music together, in sync. One person creates a room and shares its 6-character code, everyone adds songs to a shared queue, and playback stays lined up on every computer.

Download

macOS

macOS 13 or newer, Apple Silicon and Intel

Download for Mac

Unzip and move Planar to Applications. The first time you open it, macOS will block it: go to System Settings → Privacy & Security and click Open Anyway.

Windows

64-bit (x64) Windows

Download for Windows

Unzip the whole folder and run Planar.exe. If SmartScreen appears, click More info → Run anyway.

These warnings appear because the app isn't signed with a paid developer certificate yet. Both downloads always serve the newest release.

How it works

  • Playback runs through the official YouTube player, so nothing is downloaded or ripped. Clients share only video IDs and small control messages.
  • Each room has a single relay on Cloudflare Durable Objects that holds the authoritative state and acts as the shared clock.
  • Clients sync their clocks with Cristian's algorithm, and starts are scheduled about 200 ms ahead so every computer begins at the same moment.
  • Written in C++ with wxWidgets. The relay server is TypeScript.
